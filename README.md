### 🧩 Featured Projects

#### 🌤️ [DhariniGPT](https://dharinigpt.vercel.app) — Bilingual AI Weather Intelligence (Hackathon, Team AETHERX)
Conversational weather platform in English and Hindi.
- **My role — the Python backend (FastAPI):** weather/AQI proxy with SQLite caching, geocoding, saved locations, and an AI chat endpoint
- Designed a **swappable AI provider layer** — OpenAI, Anthropic, or Gemini selectable with a single env variable, tested end-to-end on all three
- Frontend gracefully falls back to direct Open-Meteo calls if the backend goes down
- Team-built features: live forecasts and historical trends, US AQI with pollutant breakdown, threshold alerts with 5-minute notifications, a Leaflet live map with wind, rainfall, and USGS earthquake data, and a "living sky" UI that tints to real conditions

`FastAPI` `Python` `SQLite` `React` `TypeScript` `Leaflet` `Open-Meteo`

#### ✅ [LIXR Fitness AI](https://lixr-fitness.web.app/) — Habit Tracker PWA (Solo)
- Offline-first PWA with **Firebase cloud sync**, calendar heatmap, analytics, achievements, and drag-and-drop
- Custom ink/paper design system with Fraunces + Manrope typography
- **Three architecture pivots** (React Native/Expo → browser React → Vite PWA), each driven by real deployment and distribution trade-offs
- Fixed non-trivial bugs in the leveling formula, persistence layer, and heatmap date ranges; optimized bundle size

`React` `TypeScript` `Vite` `Tailwind` `Firebase` `PWA`

#### 📂 [Awarna — The Smart Hybrid Organizer](https://awarnaorganiser.web.app/) (Solo)
